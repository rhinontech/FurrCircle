# FurrCircle — Expo app

Pet care, veterinary management, and trusted local community.
Product spec: `../FURRCIRCLE_VET_OWNER_PRODUCT_SPEC.md` — read it before adding features;
the privacy, consent and emergency rules in §7 are launch requirements, not polish.

## Running

```bash
npm start          # Metro; press i / a to open a simulator
npx tsc --noEmit   # typecheck (typed routes are generated by the dev server)
npx expo export --platform ios --platform android --output-dir /tmp/check   # full bundle check
```

Typed routes are on. `npx tsc --noEmit` only validates `router.push()` paths once the dev
server has written `.expo/types/router.d.ts` — start Metro at least once after adding a route.

## Design system

The palette is sampled from `assets/logo.png` — three blues from the brand mark, plus
mint / amber / coral / teal / violet for care states. Never hard-code a colour; take it
from `useTheme().tk` so light and dark both work.

Glass has three tiers, and the tier matters for performance:

| Use | Component | Cost |
| --- | --- | --- |
| List rows, cards, chips | `glassSurface(tk)` / `<GlassCard>` | Cheap — translucent fill, no blur |
| Fixed chrome only (tab bar, sheets, composers) | `<GlassBlur>` | Real backdrop blur — expensive |
| Ambient backdrop | `<AmbientBackground>` | Static gradient + SVG blobs |

`GlassBlur` in a scrolling list will drop frames on Android. It is fixed chrome only.

**Never put a gradient across the face of a glass panel.** A light-to-transparent wash over a
card is a value ramp, and a value ramp on a pale surface reads as brushed metal, not glass.
Panels are evenly tinted; the depth comes from the blue ambient ground showing through a
translucent fill. If a surface looks flat, lower the fill opacity — do not add a sheen.

Colour tokens are contrast-checked against the worst case (a panel centred on an ambient
colour blob). `text`, `textSecondary`, `textMuted` and `primary` all clear 4.5:1 there in both
themes; if you deepen the blobs or raise `glass` opacity, re-check them.

On the brand gradient cards the surface is dark in both themes, so a themed label disappears
in dark mode. Use `<Button variant="inverse">` there, not `variant="glass"` with a white
background override.

Screens follow one shape:

```tsx
<Screen>                        {/* paints AmbientBackground */}
  <ScreenHeader title="…" back />
  <ScreenScroll>…</ScreenScroll> {/* pads past the floating tab bar */}
</Screen>
```

## Platform notes

- `edgeToEdgeEnabled: true` on Android: every bottom-anchored element needs
  `Math.max(useSafeAreaInsets().bottom, fallback)`. iOS handles this on its own.
- Keyboard avoidance on Android: wrap the scroll content *and* the input bar in one
  `KeyboardAvoidingView` (`behavior="height"`). Wrapping only the input leaves the list behind.
- The tab bar animates with React Native's `Animated`, not Reanimated — a single translateX
  spring does not justify a worklets runtime, and it works in Expo Go without native setup.

## Data

Everything renders from `src/data/mock.ts`. Screens import named collections and the
`petById` / `vetById` / `clinicById` lookups, so replacing the file with API calls does not
touch the components.
